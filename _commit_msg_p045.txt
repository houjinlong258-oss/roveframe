P0-4/P0-5: approval UI last mile + production audit store

P0-4 approval UI:
- default tab is Business Actions; 8s polling while tab visible
- expandable detail: Request (agent/tool/business/user/arguments JSON),
  Risk, Approval (approved_by), Execution Status timeline (pending ->
  approved -> executing -> completed/failed with timestamps), Result
  (execution_result/last_error), audit link
- GET /api/agent/approvals returns full lifecycle fields and answers
  401 instead of 500 when unauthenticated

P0-5 production audit store:
- audit_events table (tenant/business/user/agent/tool/action/arguments_
  hash/approval/execution/timestamp/result/status) + lifecycle writes
  in approvals.ts (created/rejected/approved/executed/failed)
- /api/audit (scoped query w/ approval filter + pagination) and
  /api/audit/export (CSV)
- /audit page (table + filter + export) + sidebar entry + i18n (en/zh/es)
- tests: audit-store.test.ts
