## 6. 流程风险

**同一仓库有两个代理在写。** 本会话实测到：`AGENTS.md` 被中途改写、
`src/lib/auth-guard.ts` 与 `src/lib/migration.ts` 在我改后 2–4 分钟被对方再次写入、
`mobile` 侧新增了 `/api/website*` 与 `public_sites`。

我全程没有覆盖对方改动（逐项核验过我的编辑是否幸存），也**没有替对方加守卫**
（不掌握其设计意图）。但**任何一方执行 `git commit -a` 都会把另一方的在制品一起提交**。
