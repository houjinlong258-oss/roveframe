# 每日经营简报

老板每天早上只想知道三件事：**昨天怎么样、哪里不对、今天要我做什么决定。**

## 何时使用

- 每天固定时间自动出简报
- 老板问「昨天怎么样」「今天有什么要注意的」
- 开例会前

## 需要的数据

1. 营收、订单数、客单价（当日 / 近 7 日均值 / 上周同日）
2. 时段分布（哪个时段掉了）
3. 异常：差评、缺货、预约冲突、支付失败、系统告警
4. 待审批事项

## 步骤

1. **先给结论，再给数据。** 一句话说清「比基线好还是差，差在哪」。
2. 与**近 7 日均值**比，不要与「昨天」比 —— 餐饮的星期效应会让日环比全是噪音。
   有上周同日数据时优先用同日对比，并注明口径。
3. 营收下滑时做**归因尝试**（订单数 vs 客单价，哪个在掉；哪个时段在掉），
   归因不确定就直说「原因待查」，不要编一个听起来的解释。
4. 异常按**紧急度**排序，每条给「谁去做什么」。
5. 待办只列**今天需要老板决策**的，不要把执行细节堆进去。

## 输出格式

```
一句话结论：…

数据：营收 / 订单 / 客单 （对比基线 + 百分比）
结构：时段分布、畅销与滞销
异常：N 条（按紧急度）
今天要你决定的：N 条
```

## 边界

- **营收为 0 或数据缺失时如实说**，不要用"暂无数据"含糊过去 —— 要说明是接口没数据还是当天确实为 0。
- 不把「AI 建议」写成既成事实；建议要与数据分开呈现。
- 涉及金额一律用本店货币与两位小数，注明是否含税。
