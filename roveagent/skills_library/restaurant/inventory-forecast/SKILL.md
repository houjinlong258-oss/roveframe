# 库存预测与补货建议

把「还剩多少」换算成老板真正关心的那句话：**「还能用几天，哪天必须下单」。**

## 何时使用

- 老板问「哪些东西要补货了」「会不会断货」
- 每天/每周固定巡检
- 出现缺货告警时

## 需要的数据

1. 当前库存量与单位
2. 近 7 / 14 / 30 天的**消耗量**（有订单明细就用明细，没有就用盘点差值）
3. 供应商**交货周期**（下单到到货的天数）—— 知识库的 `supplier-contacts.md`
4. 保质期 / 易腐性（生鲜与干货的补货策略不同）

## 步骤

1. 算日均消耗 = 期间消耗 ÷ 天数。
2. 算可用天数 = 当前库存 ÷ 日均消耗。
3. 算**再订货点** = 日均消耗 × 交货周期 + 安全库存。
   - 安全库存取「交货周期的消耗量 × 0.3」起步；生鲜可更低、干货可更高。
   - 消耗波动大（标准差高）时把安全库存上调，并说明理由。
4. 分三档输出：
   - **立即下单**：可用天数 ≤ 交货周期
   - **本周内下单**：可用天数 ≤ 交货周期 × 1.5
   - **正常**：其余
5. 对每个「立即下单」项给出**建议数量** = 覆盖到下一个订货周期的量 − 当前库存。

## 输出格式

表格：品项 / 当前库存 / 日均消耗 / 可用天数 / 交货周期 / 建议数量 / 紧急度

结论一句话：**最早会在哪天断货，是哪一项。**

## 边界

- 数据不足时**不要外推**。少于 7 天消耗记录就说明「样本太短，仅供参考」，并只用它做定性判断。
- 不代替老板下采购单；需要下单时给出可直接转发的采购清单，由老板确认。
- 易腐品避免「一次性大量补货」的建议，除非有明确依据。
