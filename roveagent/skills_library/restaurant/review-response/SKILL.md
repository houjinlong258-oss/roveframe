# 差评回复

差评回复的目标不是"赢"，是**让看评论的潜在客人觉得这家店靠得住**。

## 何时使用

- 出现 1~3 星评价
- 老板问「这条差评怎么回」
- 每周复盘差评类型

## 需要的数据

1. 评价内容、星级、渠道、时间
2. 该客人的历史消费（是常客还是首访）—— 决定回复口径
3. 当日实际发生的事（等位时长、出餐时间、退换记录），有就引用，没有就不编

## 步骤

1. **先分类**，不同类型的回复策略完全不同：
   - **菜品质量**（口味/分量/温度）→ 认账 + 具体改法 + 邀请再试
   - **服务态度** → 认账 + 已做的具体处理（不是"会加强培训"这种空话）
   - **等待/出餐效率** → 说明当天客观情况 + 改进动作（排班/备餐）
   - **价格感知** → 不辩解，讲清价值构成，尊重对方选择
   - **误会/事实不符** → 先感谢反馈，再**平静地**补充事实，不要对抗
2. 回复必须包含三件事：**具体承认什么 + 具体改了什么 + 下一步怎么联系**。
3. 24 小时内回复；超过 48 小时的差评单独标注（回复价值已下降，但仍要回）。
4. 如果同一问题一周内出现 ≥2 次，把它升级为**经营问题**（而不是逐条回复），
   写入待办并给出根因假设。
5. 需要补偿时给**分级方案**（下次到店赠品 / 折扣 / 免单），并标明适用条件。

## 输出格式

- 回复草稿（可直接复制，控制在 120 字以内，先共情后事实后行动）
- 问题类型 + 建议补偿级别
- 线下跟进项（谁联系、什么时候）
- 若为重复问题：升级为经营问题的说明

## 边界

- **不与客人在公开评论区争辩**，也不要求删评。
- 不承诺做不到的补偿；补偿方案必须老板能兑现。
- 不泄露其他客人或员工个人信息。
- 回复是外发内容，**发出前需老板确认**。
